# PWA Studio Storefront

Production-ready Adobe Commerce PWA Studio storefront setup managed with Docker.

This repository contains the PWA Studio Venia-based frontend application and local development infrastructure.

---
# Requirements

Before starting, install:

- Docker
- Docker Compose
- Git
- Node.js 20+ (only required for local non-container development)
- Yarn 1.x

Verify:

```bash
docker --version
docker compose version
git --version
